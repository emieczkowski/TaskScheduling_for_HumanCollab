# People Intuitively Schedule Tasks to Improve Collective Efficiency

Stimuli, anonymized data, and analysis code for the CogSci 2026 paper:
"People Intuitively Schedule Tasks to Improve Collective Efficiency".

## Repository Contents

- `analysis.ipynb`: Main analysis notebook used for statistical analyses and figures.
- `public_data/offline_anonymized.csv`: Offline condition participant data (anonymized).
- `public_data/online_anonymized.csv`: Online condition participant data (anonymized).
- `stimuli/workloads.json`: Workload stimuli file used in the experiment.

## Setup

1. Create a Python environment (recommended Python 3.10+).
2. Install dependencies:

```bash
pip install -r requirements.txt
```

3. Launch Jupyter and run the notebook:

```bash
jupyter notebook analysis.ipynb
```

## Data Sharing and Anonymization

- All participant-level data included here are anonymized.
- The shared CSV files contain no direct identifiers.
